# Система WAYO

## Концепция и проблема

WAYO — сервис для тех, кто планирует поездки с друзьями или семьёй.
Обычно маршрут строят на карте, места для остановок ищут отдельно, а предложения обсуждают в чате. 
Если кто-то меняет маршрут, остальным приходится искать последнее сообщение с картой и заново сверять остановки. 
В WAYO у всех одна карта, на которой сразу видны общие правки.

## Основной функционал

В первой версии можно будет войти по коду из письма, построить маршрут с остановками, 
найти и добавить интересные места по пути, пригласить попутчиков по ссылке 
и вместе править маршрут в реальном времени. 
Готовый маршрут можно будет сохранить и открыть в навигаторе.
